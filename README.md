# ⚔️ Hive Raid App

A personal use web app to coordinate party members for FF14 raids.


## Quick Start

```bash
# Install dependencies
npm install

# Start the server
npm start

# Or use watch mode for development (Node 18+)
npm run dev
```

The app runs at **http://localhost:3000** by default.

## Usage

1. Go to `/admin` to create a new raid event
2. On the main page `/`, click a raid card to view it
3. On the event page, fill in your character name, pick your job, and hit **Join Raid**
